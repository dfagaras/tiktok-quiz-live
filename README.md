# TikTok Quiz Live

MVP pentru un quiz automat de TikTok LIVE, construit în TypeScript.

## V1
- Adevărat / Fals
- rundă automată de 10 secunde
- scoring + bonus de viteză
- streak-uri
- leaderboard
- simulator local de spectatori
- Socket.IO în timp real
- pregătit pentru integrarea TikFinity și TTS

## Pornire

```bash
npm install
npm run dev
```

Deschide `http://localhost:3000`.

Apasă **Simulează 25 spectatori** sau introdu un nume și trimite A/F.
